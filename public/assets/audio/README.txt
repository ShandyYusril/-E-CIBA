# Folder Audio Narasi

Masukkan file rekaman suara per adegan di folder ini.

Format penamaan:

- scene-01.mp3
- scene-02.mp3
- scene-03.mp3
- dan seterusnya (scene-01.mp3 s.d. scene-10.mp3)

Website akan otomatis memutar file tersebut saat tombol "Suara Cerita" ditekan.
Jika file belum tersedia, aplikasi tetap aman dan menggunakan Text-to-Speech (TTS) Bahasa Indonesia sebagai cadangan.
